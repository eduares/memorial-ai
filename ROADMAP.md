# Roadmap — Memorial Inteligente

## REV00 — Linha de Base ✅

Primeira versão utilizada para estabelecer a linha de base da experimentação.

- [x] Interface Web com Streamlit
- [x] Upload de memoriais descritivos
- [x] Extração de conteúdo dos documentos
- [x] Fragmentação do texto em chunks
- [x] Geração de embeddings
- [x] Armazenamento em PostgreSQL com pgvector
- [x] Recuperação de informações
- [x] Utilização de modelo de linguagem local
- [x] Extração dos parâmetros avaliados
- [x] Experimentação com memoriais sintéticos
- [x] Estabelecimento da linha de base

## REV01 — Aprimoramento da Solução ✅

Versão utilizada na segunda etapa de experimentação, mantendo a arquitetura geral e incorporando ajustes identificados a partir da análise da REV00.

- [x] Ajustes na extração de documentos DOCX
- [x] Reingestão dos documentos utilizados na experimentação
- [x] Aprimoramento da recuperação do escopo técnico
- [x] Aprimoramento da recuperação da quantidade de profissionais
- [x] Aprimoramento da recuperação do prazo de pagamento
- [x] Ajustes nas regras de extração
- [x] Nova etapa de experimentação
- [x] Avaliação comparativa com a REV00
- [x] Organização dos resultados da experimentação

## Próximas etapas

### Aprimoramento da recuperação e extração

- [ ] Avaliar novas estratégias de recuperação de informações
- [ ] Ampliar a avaliação para diferentes estruturas de documentos
- [ ] Avaliar novos parâmetros relevantes para o processo de orçamentação
- [ ] Aprimorar a organização das informações extraídas
- [ ] Avaliar a solução com documentos de maior diversidade

### Validação em ambiente produtivo

- [ ] Realizar testes em ambiente produtivo
- [ ] Avaliar o desempenho da solução com documentos reais
- [ ] Comparar os resultados obtidos com o processo atualmente realizado pelos orçamentistas
- [ ] Identificar oportunidades de melhoria a partir do uso da solução

### Evolução da solução

- [ ] Desenvolver a segunda etapa do projeto, voltada ao preenchimento automático da planilha de preços
- [ ] Integrar as informações extraídas ao processo de orçamentação
- [ ] Avaliar a utilização de agentes especializados para diferentes etapas do processo
- [ ] Integrar a solução a outros sistemas utilizados no processo de orçamentação

---

## Objetivo futuro

Evoluir o Memorial Inteligente de um protótipo experimental para uma solução de apoio ao processo de orçamentação, ampliando sua capacidade de interpretação de documentos e integração com as etapas subsequentes do processo.
