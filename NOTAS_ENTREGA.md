# Observações para a entrega

- Os comentários adicionados aos arquivos de código têm caráter documental.
- A lógica, a ordem das etapas e a estrutura funcional do código fornecido foram preservadas.
- O README geral foi atualizado para apresentar a evolução da REV00 para a REV01.
- Os resultados foram organizados por etapa de experimentação em `docs/resultados/Etapa 1`, `docs/resultados/Etapa 2` e `docs/resultados/Tabelas`.
- A pasta `docs/referencias/` foi removida, pois as referências bibliográficas e a fundamentação acadêmica já fazem parte do TCC.
- A pasta docker/ foi removida do repositório, pois os arquivos nela contidos não são necessários para a documentação ou execução da versão atual do projeto. O Docker permanece como parte do ambiente utilizado no desenvolvimento da solução.
- REV00 e REV01 identificam as versões da solução; Etapa 1 e Etapa 2 identificam as etapas de experimentação do TCC.
- A versão atual é descrita como resultado da evolução experimental, sem afirmar causalidade absoluta entre cada ajuste e o desempenho.
- Os memoriais utilizados na experimentação são sintéticos e foram produzidos especificamente para os testes.
